# Звіт до лабораторних робіт

## Лабораторна робота 4. Git у терміналі

1. **Що змінилося у виводі `git status` після `git add`?**
   Файл перемістився зі списку невідстежуваних (Untracked files, червоний колір) у зону індексу — Changes to be committed (зелений колір).

2. **Що показує `git diff`?**
   Команда показує построкову різницю між поточними незбереженими змінами у робочій директорії та останнім комітом (рядки з `+` — додані, з `-` — видалені).

3. **Чим відрізняється `git switch main` від `git merge`?**
   `git switch main` лише перемикає робочий простір на гілку `main`, тоді як `git merge` об'єднує історію та зміни з іншої гілки в поточну.

4. **Чому виник конфлікт і як ти його розв'язав?**
   Конфлікт виник через те, що в гілках `main` та `ukr-title` було по-різному змінено один і той самий рядок заголовка `<h1>`. Я вручну відредагував файл, об'єднав обидва варіанти в один рядок, видалив службові маркери (`<<<<<<<`, `=======`, `>>>>>>>`) і зробив коміт злиття.
